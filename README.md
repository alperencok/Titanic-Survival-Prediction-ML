# Titanic Survival Prediction

A machine learning project exploring the Titanic passenger dataset with exploratory data analysis (EDA), data cleaning, feature preprocessing, and a binary classification model (Logistic Regression) to predict passenger survival.

## Overview

- **Exploratory Data Analysis (EDA):** Analyzes passenger survival rates by gender, ticket class, age distributions, and fare.
- **Data Preprocessing:** Handles missing values, encodes categorical variables, and scales numerical features.
- **Classification Model:** Trains and evaluates a Logistic Regression classifier, reporting accuracy, confusion matrix, and ROC-AUC metrics.

## Project Structure

- `Titanic_Survival_Prediction.ipynb`: Jupyter Notebook containing the full analysis and model training pipeline.
- `titanic.csv`: The passenger dataset.
- `requirements.txt`: Python package dependencies.
- `assets/`: Exported visualization plots.

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/alperencok/Titanic-Survival-Prediction-ML.git
   cd Titanic-Survival-Prediction-ML
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Open the notebook:
   ```bash
   jupyter notebook Titanic_Survival_Prediction.ipynb
   ```
